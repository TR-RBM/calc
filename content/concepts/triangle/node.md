Level: isced-1
Prerequisites: angle, sides-and-corners
Rests on: M-GEO-D-017
Sources: openstax-prealgebra-2e

## Pattern third-angle-radians
```calc
x |-> y |-> pi - x - y
```
```calc
x |-> y |-> x > 0 and y > 0 and x + y < pi
```

## Pattern third-angle-degrees
```calc
x |-> y |-> 180 deg - x - y
```
```calc
x |-> y |-> x > 0 and y > 0 and x + y < 180 deg
```
