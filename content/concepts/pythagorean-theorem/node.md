# pythagorean-theorem

Level: isced-2
Prerequisites: triangle
Rests on: M-FAN-S-029
Sources: openstax-prealgebra-2e

## Pattern hypotenuse-from-legs
```calc
a |-> b |-> sqrt(a^2 + b^2)
```
```calc
a |-> b |-> a > 0 and b > 0
```

## Pattern leg-from-hypotenuse-and-leg
```calc
c |-> a |-> sqrt(c^2 - a^2)
```
```calc
c |-> a |-> a > 0 and c > a
```
